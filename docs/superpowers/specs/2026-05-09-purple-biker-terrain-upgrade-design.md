# Purple Biker 地面色アップデート設計

**作成日**：2026-05-09  
**プロジェクト**：Purple Biker  
**目的**：地面ブロックをメタリック・ダークグラデーション + 時間帯対応発光ラインで、最先端ゲーム風のリアルな質感を実現

---

## 1. 概要

現在の地面色は単色の灰色（`#808080`昼間 / `#06051b`夜間）でチープな見た目になっていた。これを**光沢感のあるメタリック・グラデーション** + **時間帯に応じた発光ライン**に変更し、最先端ゲームのような洗練された見た目を実現する。

---

| 時間帯 | ブロック色 | 境界線色 | グロー |
|--------|----------|---------|--------|

| 夜間 | `#06051b` | `#9b5bff` | なし |

## 3. 新しい実装仕様

### 3.1 グラデーション色（ブロック本体）

各ブロックに対して、上部から下部へのリニアグラデーションを適用。

**昼間のグラデーション**
```
上部：#3a4a5e（明るめダークメタリック）
下部：#1a2a3e（暗いメタリック）
効果：光が上から当たるような立体感
```

**夜間のグラデーション**
```
上部：#1a2a3e（暗いメタリック）
下部：#000005（ほぼ黒）
効果：ネオン光に照らされた高級感のある質感
```

**実装方法**
- Canvas API の `createLinearGradient()` を使用
- グラデーション方向：ブロック上端（y） → ブロック下端（y + h）
- 各ブロックごとにグラデーションを生成

### 3.2 発光ライン（上部境界線）

ブロック上部に、時間帯に応じた発光ラインを描画。既存の境界線描画コードを置き換える。

**昼間の発光ライン**
```
色：rgba(255, 255, 255, 0.6)（薄い白、60%不透明度）
線幅：3px
グロー効果：
  - shadowColor: 'rgba(255, 255, 255, 0.4)'
  - shadowBlur: 8
効果：上品な光の反射
```

**夜間の発光ライン**
```
色：#ff00ff（ネオンマゼンタ）
線幅：3px
不透明度：0.8（80%）
グロー効果：
  - shadowColor: '#ff00ff'
  - shadowBlur: 12
  - 拡張：globalAlpha = 1.0 を明示設定
効果：派手なネオン感、Purple Bikerの世界観を強調
```

**実装方法**
- ブロック上部の y 座標に水平線を描画
- `isDaytime` 変数で昼夜を判定し、対応する色とグロー設定を適用

## 4. 実装の安全性・バグ防止

### 4.1 既存コードとの互換性
- **isDaytime変数**：既に動作確認されている昼夜判定ロジックを再利用
- **ブロックデータ構造**：変更なし（既存コードとの互換性確保）
- **描画フロー**：既存の描画ループ内で色設定を置き換えるのみ

### 4.2 パフォーマンス考慮
- グラデーションオブジェクトはフレームごとに生成（Canvas の best practice）
- グロー効果は shadowColor / shadowBlur で実装（リソース軽量）
- 既存コードの処理順序は変更しない

### 4.3 バグ防止措置

**色コード確認**
- 全色コードを 16 進数で統一（`#RRGGBB` または `rgba(r, g, b, a)` 形式）
- 色の数値範囲確認（0-255 または 0-1）

**グラデーション生成**
- グラデーション座標：`createLinearGradient(sx, block.y, sx, block.y + block.h)`
- `sx`（スクリーン座標）と `block.y`（ワールド座標）の混在を確認して対応

**昼夜の色遷移**
- 昼夜が切り替わる時（背景色が変わるのと同時）に地面色も変わることを確認
- 暫定的に夜と昼の両方をプレイして視認性を検証

**既存コードの削除**
- 古い単色描画コード（`ctx.fillStyle = '#808080'` など）を確実に削除
- 削除後、同じ箇所で新しいグラデーション処理を追加

### 4.4 テスト項目
1. 昼間プレイ：グラデーション色が正しく表示される
2. 夜間プレイ：ネオンマゼンタの発光ラインが正しく表示される
3. 昼夜切り替え：背景と地面の色がスムーズに遷移する
4. プレイヤー視認性：グラデーション背景でもプレイヤーが見やすい
5. パフォーマンス：フレームレートに影響がない（60fps 維持）
